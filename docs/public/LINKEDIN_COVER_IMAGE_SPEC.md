# LinkedIn Cover Image Spec

This cover image supports the public build note for Evidence-Bound Clinical Review Toolkit.

## Safety Requirements

The cover image must not include:

- patient images
- X-rays
- dental photos
- medical device imagery
- hospital or emergency imagery
- clinical AI claims
- diagnosis or treatment wording
- production, compliance, HIPAA, or medical-device claims

## Cover Text

Title:

Evidence-Bound Clinical Review Toolkit

Subtitle:

Making AI-generated healthcare-adjacent output reviewable

Footer:

Portfolio prototype · Not for clinical use

## Visual Concept

Use abstract workflow language only.

The visual should show a simple horizontal workflow diagram:

```text
AI Draft -> Evidence -> Missing Context -> Human Review -> Audit Trail
```

## Style

- 1200 x 627 dimensions
- neutral professional palette
- clean layout
- restrained technical feel
- no patient-facing or clinical product styling
- no medical iconography
