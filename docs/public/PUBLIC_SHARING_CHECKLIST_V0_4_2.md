# Public Sharing Checklist for v0.4.2

Use this checklist before sharing the LinkedIn article, feed post, or cover image publicly.

## Positioning

- [ ] Article avoids clinical AI overclaim.
- [ ] Article says this is not a clinical decision tool.
- [ ] Article says this is not for clinical use.
- [ ] Article frames the project as review infrastructure for AI-generated healthcare-adjacent outputs.
- [ ] Article does not present the project as deployed clinical software.

## Safety Claims

- [ ] No diagnosis claim.
- [ ] No treatment recommendation claim.
- [ ] No clinical correctness validation claim.
- [ ] No medical safety claim.
- [ ] No patient-facing advice claim.
- [ ] No HIPAA compliance claim.
- [ ] No production readiness claim.
- [ ] No medical-device claim.
- [ ] No real patient data claim.

## Links

- [ ] GitHub repository link points to: https://github.com/ClinicBrain-ai/evidence-bound-clinical-review-toolkit
- [ ] Release link points to: https://github.com/ClinicBrain-ai/evidence-bound-clinical-review-toolkit/releases/tag/v0.4.2

## Cover Image

- [ ] Cover image has no patient imagery.
- [ ] Cover image has no clinical imagery.
- [ ] Cover image has no X-ray, dental photo, hospital, emergency, or medical-device imagery.
- [ ] Cover image uses abstract workflow language only.
- [ ] Cover image includes "Not for clinical use."

## Owner Review

- [ ] Owner reviews article before posting.
- [ ] Owner reviews feed post before posting.
- [ ] Owner reviews cover image before posting.
- [ ] Owner confirms no public post is published automatically.
