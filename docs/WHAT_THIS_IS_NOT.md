# What This Is Not

This repository is a portfolio prototype for healthcare-adjacent AI output review infrastructure.

It does not:

- diagnose patients
- recommend treatment
- replace clinicians
- validate clinical correctness
- use real patient data
- claim HIPAA compliance
- claim production readiness
- function as a medical device

It is not intended for real patient use, clinical deployment, patient-facing advice, second opinions, or autonomous medical decision-making.
