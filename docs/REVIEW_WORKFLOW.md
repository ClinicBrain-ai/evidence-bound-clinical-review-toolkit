# Review Workflow

```text
Synthetic case summary
  -> AI-generated draft output
  -> Evidence mapping
  -> Missing-information flags
  -> Risk level
  -> Human review requirement
  -> Reviewer decision
  -> Audit event
```

## Workflow Steps

1. Synthetic case summary

   A de-identified, fictional case summary provides the source material.

2. AI-generated draft output

   An AI-generated healthcare-adjacent draft is captured as text. The draft is not treated as clinically validated.

3. Evidence mapping

   Statements in the draft are mapped to available source details where possible.

4. Missing-information flags

   Important unavailable information is listed explicitly.

5. Risk level

   A conservative risk level is assigned for review routing.

6. Human review requirement

   The packet states whether human review is required before any downstream use.

7. Reviewer decision

   A reviewer records whether the output is approved, revised, rejected, or escalated.

8. Audit event

   Key review actions are logged for traceability.
